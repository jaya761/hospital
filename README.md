## 🚀 Deployment to Vercel

This repository is ready for zero-configuration static deployment on [Vercel](https://vercel.com):

### Option 1: Vercel CLI
```bash
npm i -g vercel
vercel
```

### Option 2: GitHub / GitLab / Bitbucket
1. Push this directory to your Git repository.
2. In the Vercel Dashboard, click **Add New Project** and select your repository.
3. Leave Build Command and Output Directory as default (static site).
4. Click **Deploy**.
